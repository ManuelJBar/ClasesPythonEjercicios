# Ejercicios de Python – Nivel principiante

Colección de 6 ejercicios básicos para practicar sintaxis de Python:
variables, tipos de datos, condicionales, bucles, listas y funciones.

## Estructura

- `enunciados/` — archivos con el enunciado y huecos (`TODO`) para completar.
- `soluciones/` — una posible solución de cada ejercicio.

## Índice de ejercicios

| # | Archivo | Tema |
|---|---------|------|
| 1 | `01_hola_mundo.py` | `input()`, `int()`, f-strings |
| 2 | `02_calculadora_basica.py` | Operadores aritméticos, `if/elif/else` |
| 3 | `03_par_impar.py` | Condicionales, operador módulo `%` |
| 4 | `04_tabla_multiplicar.py` | Bucle `for`, `range()` |
| 5 | `05_lista_notas.py` | Listas, funciones, `max()`/`min()` |
| 6 | `06_adivina_numero.py` | Bucle `while`, módulo `random` |

## Cómo usarlos

1. Abre el archivo correspondiente en `enunciados/`.
2. Completa las partes marcadas con `# TODO`.
3. Ejecuta el archivo con `python nombre_archivo.py`.
4. Compara tu solución con la de `soluciones/` si te atascas.
